# Migration Guidance for Codex

Use the current ai-augmented.ai site as source material.

For every current page or content block, classify it as:

- keep
- move
- merge
- redirect
- retire

Map role-specific content into:

`/{domain}/{role}/{support}/`

Keep shared framework content global under:

- `/framework/maturity/`
- `/framework/aaos/`

Move concrete workflows and examples into:

- `/practice/`

Do not invent facts, testimonials, customers, or metrics during migration.

Preserve useful source content but rewrite page composition to match the four approved layouts.
