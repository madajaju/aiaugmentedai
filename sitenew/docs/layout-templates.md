# Static Site Layout Standard

## Canonical hierarchy

**Domain → Role → Support**

Examples:
- `/business/team/apply/`
- `/education/teacher/learn/`
- `/legal/firm/augment/`
- `/medical/clinician/apply/`

## The four layouts

1. **Domain Landing** — domain roots such as `/education/`
2. **Role Landing** — role roots such as `/education/teacher/`
3. **Support Landing** — support roots such as `/education/teacher/apply/`
4. **Editorial / Practice / Framework** — deep readable pages such as `/framework/aaos/controls/`

## Readability rules

- prose width: about 65–75 characters
- cards only for choices and curated resources
- use narrative transitions between sections
- no more than roughly 6–8 major sections on landing pages
- one primary decision per screen
- mobile-first
- all meaningful content must exist in static HTML
