# Static SEO / AEO Requirements

Every canonical page must:

- be a real static HTML file
- have a unique title
- have a unique meta description
- have one H1
- include meaningful visible body copy in initial HTML
- include a canonical URL
- use semantic headings
- include internal links
- be included in sitemap.xml
- avoid unintended `noindex`
- provide OpenGraph metadata
- use structured data where appropriate

Do not rely on JavaScript-rendered primary copy.
Do not use query-string-only views as substitutes for canonical static pages.
